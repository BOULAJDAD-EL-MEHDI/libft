# Instructions

The first thing I want to explain is how this project works:

- I use a header file and a Makefile to make this project easier to manage.
- The project is composed of four parts:
  - C source files
  - Header file
  - Makefile
  - README file
- To create the library, run:
	```
	make && make clean
- To use one of the functions, compile your program with:
	```
	cc main.c libft.a
